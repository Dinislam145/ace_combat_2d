# Cleared to Land

Метрическая сцена полёта на Phaser AE. Описание поведения и критерии приёмки находятся в [задании на первую итерацию](../docs/01-metric-flight-scene.md).

## Локальный запуск

Выполняй из корня репозитория, где установлен движок Phaser AE в папке `phaser/`.

```sh
npm run serve
```

Если в окружении доступен Node.js без npm, ту же команду можно запустить через `node phaser/cli/bin/phaser-ae.mjs serve`.

Открой [http://localhost:4173/](http://localhost:4173/). Самолёт сразу летит на север из `(0, 0)` со скоростью 600 км/ч и РШГ на 50%. **A/D** поворачивают самолёт, **W/S** меняют положение РШГ на 25 процентных пунктов в секунду. При отпускании клавиш выбранные курс и тяга сохраняются. В HUD видны координаты, скорость, тяга и курс.

Тяга растёт пропорционально положению РШГ от 0 до 65 300 Н. Если удерживать W при 100% РШГ, форсаж даёт 106 000 Н. При массе 12 000 кг ускорение рассчитывается по формуле `a = F / m − k × v_current`, где `k = 0,02 с⁻¹`, а `v_current` — текущая скорость в м/с. На каждом тике скорость обновляется по формуле `v_new = v_current + a × dt` и ограничивается диапазоном 0–1470 км/ч.

Для сборки в `dist/` используй `npm run build`. Команда `npm run smoke -- --seconds 3` запускает браузерную проверку Phaser AE с установленным Chromium для Playwright.

## Исходники

- `main.ts` регистрирует и запускает сцену.
- `scenes/FlightScene.ts` связывает шаг симуляции, самолёт, камеру и HUD. В инспекторе сцены доступно состояние полёта, идентификатор спрайта начинается с `aircraft`.
- `flight/flightModel.ts` хранит и обновляет положение и скорость независимо от Phaser AE.
- `art.ts` загружает PNG самолёта. `view/oceanGrid.ts` рисует видимые линии сетки. `view/flightHud.ts` форматирует и показывает телеметрию.

Phaser AE генерирует `engine.ts` и справочник API в `game/docs/` при сборке. Модель использует шаг движка в секундах, хранит курс в градусах и переводит его в радианы для вычисления перемещения.
