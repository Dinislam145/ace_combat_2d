# Cleared to Land

Метрическая 3D-сцена полёта на Phaser AE. Управляемый low-poly F-16 летит над островом с одной горой. Масштаб мира — один метр на координатную единицу. [ТЗ на первый 3D-прототип](../docs/02-low-poly-3d-flight.md)

## Локальный запуск

Выполняй из корня репозитория, где установлен движок Phaser AE в папке `phaser/`.

```sh
npm run serve
```

Если в окружении доступен Node.js без npm, ту же команду можно запустить через `node phaser/cli/bin/phaser-ae.mjs serve`.

Самолёт сразу летит на север из `(0, 0)` на высоте 160 м со скоростью 600 км/ч и РШГ на 50%. **A/D** поворачивают самолёт, **W/S** меняют положение РШГ на 25 процентных пунктов в секунду. При отпускании клавиш выбранные курс и положение РШГ сохраняются. В HUD видны координаты карты, высота, скорость, тяга и курс. [Открыть игру](http://localhost:4173/)

Тяга растёт пропорционально положению РШГ от 0 до 65 300 Н. Если удерживать W при 100% РШГ, форсаж даёт 106 000 Н. При массе 12 000 кг ускорение рассчитывается по формуле `a = F / m − k × v_current`, где `k = 0,02 с⁻¹`, а `v_current` — текущая скорость в м/с. На каждом тике скорость обновляется по формуле `v_new = v_current + a × dt` и ограничивается диапазоном 0–1470 км/ч.

Для сборки в `dist/` используй `npm run build`. Команда `npm run smoke -- --seconds 3` проверяет три секунды симуляции и загрузку ассетов в headless-режиме Phaser AE.

## Исходники

- `main.ts` регистрирует и запускает сцену.
- `scenes/FlightScene.ts` связывает шаг симуляции, модель самолёта, камеру и HUD. В инспекторе сцены доступно состояние полёта, идентификаторы частей модели начинаются с `aircraft`.
- `flight/flightModel.ts` хранит и обновляет положение и скорость независимо от Phaser AE.
- `art.ts` загружает готовую GLB-модель. Для её пересборки из корня репозитория выполни `node tools/build-f16.mjs`.
- `view/island.ts` строит поле высот и поверхность океана. `view/flightHud.ts` форматирует и показывает телеметрию.

Phaser AE генерирует `engine.ts` и справочник API в `game/docs/` при сборке. Модель использует шаг движка в секундах, хранит курс в градусах и переводит его в радианы для вычисления перемещения.
