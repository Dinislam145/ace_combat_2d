# Как устроен проект Cleared to Land

Игровой код находится в `game/`, модели и референсы — в `assets/`, генератор модели — в `tools/`. Проект использует TypeScript и Phaser AE v3. Чтобы проследить запуск игры, начни с [game/main.ts](../game/main.ts), затем открой [FlightScene.ts](../game/scenes/FlightScene.ts).

## Игровой код

| Файл | За что отвечает |
| --- | --- |
| [game/main.ts](../game/main.ts) | Точка входа. Загружает ассеты, регистрирует `FlightScene`, запускает движок и открывает сцену `play`. |
| [game/art.ts](../game/art.ts) | Загружает 3D-модель F-16 и моноширинный шрифт HUD. Регистрирует модель под ключом `f-16in`, а шрифт под именем `mono`. |
| [game/scenes/FlightScene.ts](../game/scenes/FlightScene.ts) | Собирает сцену из острова, модели самолёта и HUD. Считывает A/D и W/S, вызывает расчёт полёта на каждом фиксированном тике и передаёт новые координаты модели и камере. Здесь заданы углы камеры, её расстояние до самолёта и масштаб модели в мире. |
| [game/flight/flightModel.ts](../game/flight/flightModel.ts) | Хранит параметры F-16 и определяет `FlightState`. Функция `createFlight` задаёт начальное состояние. Функция `advanceFlight` получает предыдущее состояние, ввод и время в секундах и возвращает новое состояние. Здесь рассчитываются тяга, форсаж, ускорение, скорость, курс и положение. Модуль работает независимо от Phaser AE. |
| [game/view/island.ts](../game/view/island.ts) | Строит остров по функции высоты при входе в сцену. Задаёт форму горы, цвета склонов, освещение и плоскость океана. |
| [game/view/flightHud.ts](../game/view/flightHud.ts) | Создаёт экранные надписи и обновляет их по `FlightState`. Здесь скорость переводится из м/с в км/ч для отображения, а индикатор форсажа показывает красную надпись WEP. |
| [tools/build-f16.mjs](../tools/build-f16.mjs) | Офлайн-генератор F-16. Содержит сечения фюзеляжа, контуры крыльев и оперения, а также материалы. Команда `node tools/build-f16.mjs` из корня записывает готовый GLB. |

Путь данных на одном тике выглядит так. `FlightScene` считывает клавиши → `advanceFlight` рассчитывает `FlightState` → сцена обновляет модель и фокус камеры → HUD выводит телеметрию. Текущее состояние можно посмотреть в консоли браузера через `game.inspect().state`.

### Координаты полёта и 3D-мира

Одна мировая единица равна одному метру. Модель полёта хранит `xMeters` к востоку, `yMeters` к югу и `altitudeMeters` вверх. Сцена записывает их в Phaser как `x`, `z` и `y` соответственно. Поэтому `Y` на HUD — координата карты, а высота подписана отдельно как `Altitude`. Курс хранится в градусах по часовой стрелке от севера. Сцена переводит его в радианы, чтобы повернуть 3D-модель. Север на экране сверху, восток справа.

## Ассеты

| Файл | Назначение |
| --- | --- |
| [assets/reference/F-16IN.jpg](../assets/reference/F-16IN.jpg) | Референс самолёта в трёх проекциях. Используется при работе над формой модели. |
| [assets/planes/f-16in-low-poly.glb](../assets/planes/f-16in-low-poly.glb) | Игровая 3D-модель F-16. Один бинарный файл glTF содержит геометрию, нормали и материалы. |
| [assets/planes/f-16in-top.png](../assets/planes/f-16in-top.png) | Спрайт самолёта сверху из предыдущей 2D-версии. Сохранён в репозитории для истории прототипа. |
| `phaser/examples/assets/fonts/typography/ui-mono.glb` | Локальный шрифт HUD из установки Phaser AE. Сборщик копирует его в `dist/assets/fonts/typography/`. |

В `game/assets/planes/` лежат символические ссылки на файлы из корневой папки `assets/planes/`. Например, [ссылка на GLB](../game/assets/planes/f-16in-low-poly.glb) позволяет сборщику взять модель по пути `assets/planes/f-16in-low-poly.glb` относительно `game/` и скопировать её по тому же относительному пути в `dist/`. В игру попадают файлы, перечисленные в `manifest.assets`. Сейчас это модель F-16 и шрифт. Геометрию острова и моря сцена строит в коде.

## Конфигурация, сборка и документация

| Путь | Что там находится |
| --- | --- |
| [game/manifest.json](../game/manifest.json) | Размер экрана, список ассетов для сборки, пакеты Phaser AE и настройки проекта. |
| [game/manifest.lock.json](../game/manifest.lock.json) | Версии и порядок подключения пакетов, разрешённые сборщиком. Файл обновляется при сборке. |
| [game/assets.json](../game/assets.json) | Декларации именованных групп загрузчика Phaser AE. Сейчас группы `title` и `game` пустые, загрузка прописана в `art.ts`. |
| [game/tsconfig.json](../game/tsconfig.json) | Настройки TypeScript и разрешения импортов. |
| [package.json](../package.json) | Команды запуска, сборки и проверки. Из корня `npm run serve` поднимает локальную игру, `npm run build` собирает её в `dist/`, `npm run typecheck` проверяет типы. [Подробности запуска](../game/README.md) |
| `game/engine.ts` и `game/docs/` | Сгенерированные Phaser AE точка доступа к движку и справочник API подключённых пакетов. Настройки движка меняются через манифест. |
| `phaser/` и `game/node_modules/` | Локальная установка движка, инструментов и пакетов. |
| `dist/` | Результат сборки для браузера. |
| `docs/` | Документы проекта, включая [первую метрическую сцену](01-metric-flight-scene.md) и [ТЗ и приёмку 3D-прототипа](02-low-poly-3d-flight.md). |

Если нужно поменять поведение самолёта, начни с `flightModel.ts`. Для раскладки клавиш и ракурса открой `FlightScene.ts`, для формы острова и света — `island.ts`, для показаний на экране — `flightHud.ts`, для геометрии F-16 — `tools/build-f16.mjs`.
