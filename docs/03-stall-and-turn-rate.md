
# ТЗ 03. Сваливание и зависимость скорости поворота от скорости полёта

Целевой файл — `docs/03-stall-and-turn-rate.md`. Сейчас активен режим планирования, поэтому файл ещё не создан. Ниже готовое ТЗ для агента.

## 1. Ожидаемое поведение

У каждого самолёта есть расчётная скорость сваливания `v_stall`. Она определяет пороги входа и выхода из сваливания, а также влияет на предельную скорость поворота при удержании A или D.

Для текущего F-16 стартовая скорость составляет 600 км/ч. При такой скорости полный ввод даёт около **16,32°/с**. При разгоне угловая скорость сначала растёт, достигает максимума около **818 км/ч**, затем убывает из-за ограничения перегрузки. При нулевой скорости самолёт сохраняет курс.

Для этой итерации принято следующее игровое поведение. Сваливание выражается состоянием `isStalling`, доступным в инспекторе. Самолёт продолжает горизонтальный полёт на высоте 160 м. При удержании A/D скорость поворота определяется одной и той же формулой по обе стороны порога. Это позволяет проверить механику до добавления снижения, крена или отдельной индикации.

## 2. Параметры самолёта и среды

Ввести тип `AircraftSpecs` для характеристик самолёта. Перенести в него существующие параметры F-16, включая массу и тягу двигателя. Добавить следующие поля:

| Поле | F-16 | Смысл |
|---|---:|---|
| `massKg` | 12 000 кг | Одна масса для расчёта ускорения и скорости сваливания |
| `wingAreaM2` | 27,9 м² | Площадь крыла |
| `maxLiftCoefficient` | 1,2 | Максимальный коэффициент подъёмной силы в принятой конфигурации |
| `structuralLoadFactorLimit` | 9 | Безразмерный предел перегрузки. Ускорение свободного падения входит в формулу отдельно |

Общие параметры среды задать один раз в `FlightEnvironment`: `airDensityKgM3 = 1.225` и `gravityMps2 = 9.81`. Для пары «самолёт + среда» при создании полёта вычислять:

```text
stallSpeedMps = sqrt(2 × massKg × gravityMps2 /
                    (airDensityKgM3 × maxLiftCoefficient × wingAreaM2))
```

У F-16 получается **75,7669 м/с**, или **272,7607 км/ч**. В профиле хранятся исходные ТТХ, а `stallSpeedMps` выводится из них. Так изменение массы, площади крыла или плотности воздуха автоматически даёт согласованный порог.

## 3. Интеграция в модель полёта

Основная точка изменения — [flightModel.ts](/Users/dinislam/Projects/ace_combat2d/game/flight/flightModel.ts). Добавить к `FlightState` поля `stallSpeedMps` и `isStalling`. Передавать профиль самолёта и среду в модель так, чтобы `createFlight()` и существующий вызов `advanceFlight(state, dt, turn, throttle)` по умолчанию обслуживали текущий F-16. Для полёта с другим профилем создание и последующие тики должны использовать одни и те же ТТХ, в том числе при расчёте тяги и ускорения.

**Порядок одного фиксированного тика:**

1. Обработать РШГ и WEP. Вычислить ускорение по скорости в начале тика, затем обновить скорость и применить существующие ограничения. Полученную скорость в м/с обозначить `v`.
2. Обновить `isStalling` по `v` и состоянию предыдущего тика. При `v < 0.95 × stallSpeedMps` установить `true`. При `v > 1.05 × stallSpeedMps` установить `false`. Во всём промежутке, **включая точное равенство любому порогу**, сохранить предыдущее значение. При создании полёта начальное значение равно `initialSpeedMps < 0.95 × stallSpeedMps`.
3. Вычислить доступную перегрузку `n = min((v / stallSpeedMps)², structuralLoadFactorLimit)`. При `v > 0` вычислить `turnRateRadPerSecond = n × gravityMps2 / v`. При `v = 0` задать угловую скорость равной нулю.
4. Обновить курс: `headingDegrees += turn × turnRateRadPerSecond × dt × 180 / π`. Привести результат к диапазону `[0, 360)`. Удалить старые константы полного виража и множитель `× 2`: новую угловую скорость целиком задаёт формула.
5. По обновлённым курсу и скорости вычислить перемещение существующим способом. Курс 0° ведёт на север, 90° — на восток. `turn` равен `−1` для A, `+1` для D и `0`, когда обе клавиши отпущены или нажаты одновременно.

[FlightScene.ts](/Users/dinislam/Projects/ace_combat2d/game/scenes/FlightScene.ts) уже передаёт ввод в `advanceFlight` и публикует `FlightState` через `game.inspect.state`. Расчёт сваливания и поворота должен целиком принадлежать модели. Сцена применяет полученный курс к 3D-модели, инспектор показывает `isStalling` и `stallSpeedMps`.

## 4. Приёмка

**Поворот.** Проверить чистый расчёт на заданной скорости. Значения в таблице округлены для сравнения с допуском `0,01°/с`.

| Скорость | Доступная перегрузка `n` | Скорость поворота при полном вводе |
|---:|---:|---:|
| 0 км/ч | 0 | 0°/с |
| 136,38 км/ч | 0,25 | 3,71°/с |
| 272,76 км/ч | 1,00 | 7,42°/с |
| 600 км/ч | 4,84 | 16,32°/с |
| 818,28 км/ч | 9,00 | 22,26°/с |
| 1470 км/ч | 9,00 | 12,39°/с |

**Гистерезис.** Нижний порог F-16 составляет около **259,12 км/ч**, верхний — **286,40 км/ч**. Прогнать последовательность `300 → 270 → 258 → 270 → 287 км/ч`. Ожидаемые значения `isStalling`: `false → false → true → true → false`. Отдельно проверить точное равенство обоим порогам с каждым предыдущим значением флага. В этих тестах использовать пороги в м/с, вычисленные из `stallSpeedMps` с полной точностью.

**Интеграция и регрессии.**

- Проверить A и D при одинаковом исходном состоянии. Модули приращения курса совпадают, знаки противоположны. Переход через север работает в обе стороны. На остановке курс и координаты остаются конечными.
- Проверить тик, в котором торможение пересекает нижний порог, и тик, в котором разгон пересекает верхний. Флаг должен измениться уже в результате соответствующего тика.
- Создать тестовый профиль с удвоенной площадью крыла. Его `stallSpeedMps` должен уменьшиться в `√2` раза. Удвоение плотности воздуха при исходном профиле даёт тот же коэффициент. Это проверяет, что модель действительно использует характеристики выбранного самолёта и настройки среды.
- Повторить проверку прямого полёта из предыдущего прототипа. Через 60 тиков по `1/60` с без ввода ожидаются `xMeters ≈ 0`, `yMeters ≈ −166,36`, `speedMps ≈ 166,06`, высота 160 м. Проверить включение и отпускание WEP. Исторический критерий «90° за 2,5 с» относится к предыдущей контрольной точке.
- Выполнить `typecheck`, сборку и smoke-тест. В браузере снизить РШГ, дождаться входа в сваливание, затем включить полную тягу и проверить выход через `game.inspect().state.isStalling`.
