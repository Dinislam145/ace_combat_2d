# Задание на реализацию. Метрическая сцена полёта

## Цель

Реализуй в текущем репозитории первую программную итерацию «Минимальной сцены полёта» из [общего дизайна](cleared-to-land-design.md). При открытии игры в браузере видны голубой океан с координатной сеткой, самолёт в виде треугольника и компактный HUD. Самолёт стартует из мировой точки `(0, 0)` и сразу летит прямо со скоростью 600 км/ч.

Эта итерация проверяет перевод единиц, обновление позиции по времени, слежение камеры и отображение данных. Поворот и управление тягой относятся к следующей итерации контрольной точки. В этой сцене курс и скорость постоянны.

## Состояние и движение

| Параметр | Значение |
| --- | --- |
| Масштаб модели | 1 мировая единица = 1 метр |
| Начальная мировая позиция | `x = 0`, `y = 0` |
| Оси мира | X растёт вправо, Y растёт вниз |
| Начальный курс | Вверх по кадру, вдоль отрицательной оси Y |
| Скорость | `600 / 3.6` м/с, примерно 166,67 м/с |

Храни позицию в метрах, скорость в м/с. В каждом обновлении переводи дельту времени Phaser из миллисекунд в секунды. Для текущего фиксированного курса достаточно следующей формулы:

```text
dtSeconds = deltaMs / 1000
y = y - speedMps * dtSeconds
```

X остаётся равным нулю. Используй полную точность чисел модели и округляй значения при форматировании HUD. Движение должно зависеть от суммарного времени симуляции. Например, два шага по 500 мс и один шаг по 1000 мс дают одинаковую позицию с учётом погрешности вычислений.

Пусть состояние полёта будет источником позиции и скорости для отрисовки и HUD. Держи расчёт движения доступным для проверки отдельно от Phaser, без отдельного сервера или физического движка для этой сцены.

## Кадр, камера и океан

- Стартовый логический размер кадра — **960 × 540**. При изменении размера окна сохраняй пропорции кадра.
- Стартовый масштаб камеры — **2 логических пикселя на метр**. При таком масштабе камера показывает область мира **480 × 270 м**. Применяй масштаб в отрисовке. В момент интегрирования координат продолжает действовать соотношение 1 единица = 1 метр.
- Камера следует за самолётом и держит его в центре кадра. Ориентация камеры постоянна. Самолёт в мировых координатах `(0, 0)` оказывается в центре логического кадра `(480, 270)`.
- Океан — ровная голубая заливка. Поверх неё нарисуй тонкие контрастные линии с шагом **50 м** по X и Y. Линии привязаны к мировым координатам, кратным 50. Линии `x = 0` и `y = 0` можно выделить немного сильнее, чтобы начало координат было видно при старте.
- При полёте вверх горизонтальные линии уходят вниз относительно самолёта. Сетка должна продолжаться в отрицательных координатах и заполнять весь видимый кадр. Рисуй или переиспользуй только линии в видимой области камеры. Старт обхода видимых линий можно вычислять как `floor(видимый минимум / 50) * 50`.
- Самолёт — простой заполненный треугольник с носом вверх. Для первой проверки ориентируйся на **24 логических пикселя** по длине. Фон, сетку и треугольник создай программно.

## HUD

Размести текст в левом верхнем углу кадра, поверх сетки, в экранных координатах. Он должен оставаться на одном месте при движении и сохранять читаемый размер при масштабировании мира. Обновляй его из состояния полёта. Начальные значения выглядят примерно так:

```text
X: 0.0 m
Y: 0.0 m
Speed: 600 km/h
```

Для позиции достаточно одного знака после десятичной точки. Скорость переводи обратно в км/ч умножением на 3,6. После старта Y должен уменьшаться, а X и показание скорости оставаться постоянными.

## Порядок работы

1. Проверь, как запускается проект и есть ли уже локальный стартовый проект Phaser AE. Используй существующую структуру, если она есть. Если каркас ещё не создан, добавь минимум для локального запуска сцены на выбранном для проекта Phaser AE.
2. Подключи сцену через обычную точку входа проекта. Создай начальное состояние, затем добавь обновление по времени, треугольник, камеру, сетку и HUD.
3. Запусти проект локально и проверь результат в браузере. В отчёте укажи команду запуска, фактически пройденные проверки и проблемы, которые удалось обнаружить. Эта задача заканчивается локальной проверкой.

## Критерии приёмки

1. Игра открывается через штатную команду запуска. В кадре видны голубой океан, сетка, треугольник и HUD. В браузере нет ошибок при запуске и полёте.
2. Модель инициализируется в `(0, 0)`. При перезагрузке сцены самолёт начинает полёт из той же мировой точки.
3. После 1 секунды симуляции позиция примерно `(0, -166.67)` м. После 3 секунд она примерно `(0, -500)` м. Эти значения проверяются по времени, переданному модели, без засекания времени вручную в браузере.
4. Разбиение одной секунды симуляции на равномерные и неравномерные шаги даёт одинаковую позицию с точностью до 0,01 м.
5. При непрерывном полёте сетка движется относительно самолёта и сохраняет шаг без скачков при появлении новых линий у края кадра. Самолёт остаётся в центре, HUD остаётся в углу, скорость на HUD равна 600 км/ч.
